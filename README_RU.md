# Rail Reverse

**[Мастерская Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3823129138)**

Плагин для **Workers & Resources: Soviet Republic**, который делает работу поездов ближе к настоящей
железной дороге.

### Реверс

В обычной игре при развороте локомотив мгновенно перескакивает на другой конец состава. С Rail Reverse
он остаётся на месте и **толкает вагоны назад**, как при маневрах:

- скорость при толкании не выше 25 км/ч (советская норма для маневров);
- локомотив без вагонов едет задним ходом, а не разворачивается;
- реверс включается для отдельного поезда, для всех грузовых или для всех пассажирских;
- поезда с локомотивами с обеих сторон работают как в обычной игре.

### Лимит вагонов из хаба

В обычной игре распределительный центр (хаб) заполняет поезд вагонами на всю длину своего пути.
Rail Reverse позволяет задать каждому локомотиву свой лимит: от 1 до 25 вагонов (максимум задаётся `hub_limit_max` в `railreverse.ini`).

Все настройки хранятся в файле рядом с сохранением, сам сейв не меняется.

## Что нужно

- Workers & Resources: Soviet Republic **1.1.1.9**, 64-бит.
- [Republic Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3787969749) (RML).
- DLC не нужны. Совместим с [RailPhysics](https://steamcommunity.com/sharedfiles/filedetails/?id=3776784867).

## Установка

1. Подпишитесь на [Republic Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3787969749)
   и на [Rail Reverse](https://steamcommunity.com/sharedfiles/filedetails/?id=3823129138) в Мастерской Steam.
2. Запустите RML и на вкладке **Plugins** включите **railreverse**.
3. Запускайте игру через RML.

Чтобы удалить мод, отпишитесь от него в Мастерской.

## Управление

При открытом окне поезда:

| Клавиши | Действие |
|---|---|
| `Ctrl+F9` | реверс у этого поезда |
| `Ctrl+Shift+F9` | реверс у всех грузовых |
| `Ctrl+Alt+F9` | реверс у всех пассажирских |
| `Ctrl -` / `Ctrl +` | лимит вагонов из хаба −1 / +1 |
| `Ctrl Shift -` | без лимита вагонов из хаба |

Состояние поезда показывается в углу экрана: по-русски, если игра на русском, иначе по-английски.

## Настройки

В `railreverse.ini` настраиваются клавиши, скорости, язык, положение и размер индикатора.
Каждая опция описана в самом файле. Файл лежит в
`<SteamLibrary>\steamapps\workshop\content\784150\3823129138\plugins\`. Обновление мода в Steam
перезаписывает его, так что после обновления изменения нужно внести заново.

## Как это работает

Игра разворачивает поезд как обычно, меняется только отрисовка. Каждая машина толкающего поезда
рисуется в зеркальной точке того же участка пути, поэтому локомотив остаётся на месте. Физика, сигналы
и маршруты не затрагиваются. Код игры ищется по сигнатурам. Если после обновления игры сигнатура не
найдётся, эта функция отключится, а в логе RML появится запись. Подробности в [docs/](docs/).

## Известные ограничения

- Когда хаб забирает **все** вагоны толкающего поезда, локомотив перескакивает на место первого вагона.

## Сборка

```sh
./build.sh            # собрать и установить в игру
./build.sh nodeploy   # только собрать
```

Нужен [llvm-mingw](https://github.com/mstorsjo/llvm-mingw), пути задаются в `build.sh`.
